# DAY1~48 전체 개인 데이터 검증 요약 — 2026-10-14

## 결과

- HTML 원본 2,000행의 순번 1~2000 연속성을 확인했다.
- DAY1~47의 1,880개 영단어는 PDF 1~47쪽과 순서·철자가 모두 일치했다.
- 첫 번째 뜻은 HTML과 PDF가 1,700개에서 자동 일치했다.
- 표현이 다른 180개는 18장의 PDF 행 검토표로 모두 확인했다.
- PDF 문자 매핑 오류는 렌더 화면으로 교정하고, 명백한 원문 오기 후보는 개인 감사 기록에 근거를 남겼다.
- 기존 검증 DAY48을 결합해 DAY1~48, 1,920개짜리 개인용 통합팩을 생성했다.
- 공개 내장 DAY49~50의 80개와 합치면 앱에서 DAY1~50, 총 2,000개가 된다.

- 기존 `wm2000pilot_v1` 학습기록과 schema 1 백업 형식을 변경하지 않았다.

- 8단어×5 STEP, 3회 신규·4회차 오답복습, 오답 따라쓰기·재입력·당일 재시험, 3/7/14일 복습 예약을 유지한다.

개인 통합팩을 실제 Chromium에 불러와 다음을 확인했다.

- 50 DAY·2,000개 로딩, 모든 DAY 40개 및 연속 순번
- DAY1 선택, 원본 정답 40개 제출, 8개×5 STEP 완료

- DAY50→49→48 뒤 4회차 신규 진도 없음과 오답복습
- 미제출 답·타이머·학습기록·백업 복원 유지
- iPad Pro 10.5 근사 1112×834 및 iPad Air 13 근사 1366×1024 화면

Chromium 검사는 iPadOS Safari의 Apple Pencil·Scribble 인식률을 증명하지 않는다. 실기기 점검은 `IPAD_REAL_DEVICE_CHECKLIST.md`를 따른다.

## 공개 범위

교재 데이터의 공개 복제·전송 권한은 확인되지 않았다. 통합 JSON, 원본 HTML·PDF, 상세 감사표와 렌더 이미지는 `.private/`에만 두며 GitHub와 Pages에는 올리지 않는다. 공개 저장소에는 데이터가 없는 검증 도구·절차·통계만 반영한다.
