# iPad 실제 기기 검증표 — 2000 영단어 v0.2.1

검사 대상: `https://kfcccpro-ship-it.github.io/2000_new/`  
데이터: DAY 49·DAY 50 각각 40개, 기존 학습기록 저장 키 `wm2000pilot_v1`.

## 사전 확인 (5분)

1. **관리자 → 백업 파일 저장(.json)** 실행. 현재까지 학습기록을 별도로 보관한다. 학습기록 초기화는 절대 누르지 않는다.
2. 기기 모델·iPadOS 버전·Apple Pencil 모델을 메모한다.
3. **설정 → Apple Pencil → 손글씨 입력**이 나타나고 켜져 있는지 확인. 한글 키보드를 설정한 후 Safari에서 입력 테스트.
4. 기존에 진행 중인 평가가 있다면 완주하여 저장한다. 도중 관리자 DAY 변경은 차단되어 있다.

| 검사 장치 | 화면 목표 | 펜 | OS 유의점 |
|---|---|---|---|
| iPad Pro 10.5 | 1112×834 가로 중심, 세로 회전 포함 | Apple Pencil 1세대 | iPadOS 18 공식 업데이트 대상이 아님. **최신 한국어 Scribble 지원을 보장할 수 없음** |

## 8분 필기 검증 (각 기기별)

1. 보호자 설정 → DAY 49를 입력하고 적용. **기존 완료 기록이 없어지지 않아야 함**.
2. 학생 화면 → 오늘 학습 시작. 첫 단어 `endow`, 첫 뜻 `부여하다`, 한글 문장이 차례로 등장하는지 확인.
3. 학습 뒤 평가에서 Apple Pencil로 `부여하다`를 **15초 안에 손글씨 입력**. 화면의 인식 결과와 실제 정답 일치 여부 확인.
4. 최소 10개 단어를 평가하여 한글 필기인식 성공 수/10, 평균 인식 대기시간(체감 기준)을 기록. 성공할 때까지 다시 쓰는 반복 횟수도 기록.
5. 오답을 일부러 1번 입력 → 정답 제시, 캔버스 따라쓰기, 직접 다시쓰기, 당일 오답 재시험 진행 확인.
6. 필기 도중 입력을 제출하지 않은 상태에서 Safari 새로고침 → **임시 입력이 보존되는지** 확인.
7. 같은 단어에서 5초 경과 후 새로고침 → 타이머가 15초부터 시작하지 않고 **실제 남은 시간**을 보여주는지 확인.
8. 입력하지 않고 15초 경과 → 오답 학습 화면으로 이동하는지 확인. 한글 자동인식이 늦어서 정상 입력까지 자주 '시간 초과'로 판단되는지 기록.

## 레이아웃 점검

- 가로: 영어단어, 타이머, 필기칸, 제출 버튼이 화면 밖으로 잘리지 않는가?
- 세로: 화면을 회전해도 빈 영역이나 가려지는 버튼이 없는가?
- 손글씨/키보드 전환: 키보드가 뜰 때 제출 버튼과 필기칸을 다시 찾을 수 있는가?
- 완료 후: 다음 DAY가 DAY 50→49→48 순서로 진행되는가? DAY 48은 아직 미등록이므로 '데이터 없음'이 정상.
- 다음 실제 학습일: 전날 틀린 단어가 새 DAY 앞에 등장하며 `어제 오답 · DAY xx` 배지가 표시되는가?

## 기록 및 피드백

결과 보고 예시 (민감정보 불필요):
- 기기/OS/Pencil: iPad Pro 10.5 / iPadOS xx / Pencil 1
- 한글 손글씨 인식: 10단어 중 7개 15초 이내 성공
- 빈번한 오인식: '부여하다' → '(오인식 내용)'
- 타이머 문제: 없음/있음(재현 단계)
- 화면 문제: 가로/세로 화면 캡처 1~2개

**판정 기준:** 10개 중 8개 미만이 정확히 인식되거나 지연 때문에 정상 입력이 반복해서 오답 처리되면 필기인식 방식 및 타이머 운영정책을 재설계한다. 문제를 해결하기 전까지 학습자에게 반복 실패를 요구하지 않는다.
